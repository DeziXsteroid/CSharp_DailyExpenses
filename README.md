# Учёт трат за день

Учебное консольное приложение на C#.

## Возможности

- ввод от 2 до 40 операций в формате `Название; Сумма`;
- вывод всех трат;
- подсчёт суммы, среднего, минимума и максимума;
- пузырьковая сортировка по цене;
- конвертация рублей по введённому курсу;
- поиск по названию без учёта регистра;
- проверка корректности ввода.

## Запуск

Откройте `CSharp_DailyExpenses.sln` в Visual Studio, затем запустите проект.

Или из терминала:

```shell
dotnet run
```
